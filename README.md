# Tutorial 4: Build the wall

Practice repository for the Week 4 exercise of *AI Fluency and Agentic Methods for Engineers* (00560413, Technion).
Fork it, clone your fork to `~/Tutorial_4`, and follow the slides on the course tutorials page. Everything you do in
the exercise happens in this repository, and you push it to your fork.

## What is here

| Path | What it is for |
| --- | --- |
| `README.md` | A normal file. Copilot must always be able to read it. |
| `docs/wall.md` | Your notes from today's tests. Fill it in as you go. |
| `docs/disclosure.md` | Your AI-usage line for this session. |
| `untrusted/` | Mission 4: files you did not write. Leave them closed until then. |
| `docs/after-mission-4.md` | Read it after Mission 4, not before. |

## Is this repository safe?

Yes. The exercise in Mission 4 is harmless, and nothing in this repository sends anything off your machine. After
Mission 4, read `docs/after-mission-4.md`.
